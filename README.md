# 🟢 V Jernick Samuel | Digital Proxy & Portfolio

Welcome to my personal intelligence terminal. This repository contains the source code for my interactive, AI-powered web portfolio built with Python, Streamlit, and Google's Gemini API. 

The interface is designed with a premium, high-performance aesthetic inspired by modern hardware interfaces (Nvidia/Apple) and features a fully autonomous "Digital Proxy" chatbot that acts as my digital representative.

## 🚀 Live Deployment
**Access the live terminal:** [jernick.streamlit.app](https://jernick.streamlit.app)

## 🧠 Key Features

* **Digital Proxy (AI Chatbot):** An integrated assistant powered by `gemini-3-flash-live`. The AI is context-aware, trained on a custom system prompt to answer questions about my background, skills (VLSI, Verilog, C++), and aerospace projects.
* **Bento Grid UI:** A clean, glassmorphic layout displaying key domains: Codebase, Aerospace, Entertainment, and Passions.
* **Leave a Trace (Intelligence Terminal):** A secure contact module designed to log visitor feedback and route inquiries directly to my secure server.
* **Custom Styling:** Heavy use of HTML/CSS injection to bypass standard Streamlit limitations, creating interactive neon-glow hover effects (`#00ff88`), floating animations, and a custom background pulse.
* **Media Integration:** Built-in Spotify iframe encapsulated in a custom glass container.

## 🛠️ Technology Stack

* **Framework:** [Streamlit](https://streamlit.io/) (Python)
* **AI Engine:** Google Generative AI (`gemini-3-flash-live`)
* **Styling:** Custom CSS injected via `st.markdown(unsafe_allow_html=True)`
* **Deployment:** Streamlit Community Cloud
